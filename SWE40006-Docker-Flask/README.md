# SWE40006 Docker Flask Application

A basic Python Flask web application containerised using Docker for SWE40006 Software Deployment and Evolution.

## Application

The application is a simple Flask web application that displays a confirmation message and the hostname of the Docker container running the application.

## Technologies

- Python 3.12
- Flask
- Docker
- Docker Hub
- AWS EC2
